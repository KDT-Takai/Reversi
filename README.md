# 潮汐オセロ (Tidal Reversi)

標準オセロに **「潮汐」** を加えた、これまでにないオセロです。

> 石を置いた手が 8 手たまるごとに、盤のいちばん外側の輪（28 マス）が **石ごと 1 マス回転** します。
> 回転の向きは 時計回り → 反時計回り → … と毎回入れ替わります。

角は永遠ではありません。せっかく取った角も潮汐で辺へ流され、代わりに別の石が角へ流れ込みます。
「いつもの定石」が通用しない、潮の流れを読む新しい読み合いを楽しめます。

## 遊び方

- 基本は通常のオセロです（はさんで裏返す・置けなければパス・石の多いほうが勝ち）。
- **潮汐**
  - 石を置いた手（実手）を数え、8 手ごとに発生します。パスは数えません。
  - 外周 28 マスの石と空きマスがまとめて 1 マス回転します。内側 6×6 は動きません。
  - 終局となる手では潮汐は起きません。
- 画面右に **次の潮汐までの手数と向き** が常に表示されます。盤の外側の矢印も次の回転方向を示します。
- 置けるマスは **金色の枠** で表示されます。マウスを乗せると、その手で裏返る石が橙の輪で示されます。

### モード

| モード | 内容 |
|--------|------|
| 対コンピューター | 易 / 普 / 強 の 3 段階。石の色はランダムに決まります（先手は常に黒） |
| 2人で対局 | 1 台の PC で交互にクリック。開始時に黒を持つプレイヤーを選びます |

### 操作

| 操作 | 内容 |
|------|------|
| 左クリック | 石を置く / ボタンを押す |
| H | ヘルプ（遊び方）を開く・閉じる。対局は中断され、閉じると元の状態に戻ります |
| Esc | 前の画面へ戻る（対局中はモード選択へ） |

## ビルド

必要なもの: Windows 10/11 x64、Visual Studio 2022 または Visual Studio 18（「C++ によるデスクトップ開発」）。
DxLib 3.25a は `vendor/DxLib/` に同梱済みのため、追加のインストールは不要です。

```powershell
$msbuild = & "${env:ProgramFiles(x86)}\Microsoft Visual Studio\Installer\vswhere.exe" `
  -latest -products * -requires Microsoft.Component.MSBuild -find MSBuild\**\Bin\MSBuild.exe | Select-Object -First 1
& $msbuild Reversi.sln /p:Configuration=Release /p:Platform=x64 /m
.\bin\x64\Release\CoreTests.exe     # ルールコアの自動テスト（全 PASS で終了コード 0）
.\bin\x64\Release\TidalReversi.exe  # ゲーム本体
```

`Reversi.sln` を Visual Studio で開いてビルドしても同じです（ツールセットは VS2022=v143 / VS 18=v145 を自動選択）。

## 構成

```text
src/core/   ルールコア（DxLib 非依存の純 C++20）: 盤・潮汐・規則・対局状態・AI
src/game/   DxLib による画面・入力・アニメーション・合成効果音・ヘルプ
src/tests/  CoreTests（グラフィクスなしで実行できる決定論的テスト）
specs/001-novel-othello/  Spec Kit による仕様・計画・タスク
```
