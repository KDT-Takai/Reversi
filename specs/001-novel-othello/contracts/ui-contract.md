# UI Contract: 潮汐オセロ (Tidal Reversi)

デスクトップアプリの外部契約（画面フロー・HUD・入力）。実装は `src/game/`、状態名は data-model.md の GameFlow と一致させる。

## Window

- 固定サイズウィンドウ 1280x720、タイトル「潮汐オセロ」。リサイズ不可。
- 60FPS 固定ループ。閉じる操作で即終了（確認ダイアログなし）。

## Screen flow (状態契約)

| State | 表示 | 入力→遷移 |
|-------|------|-----------|
| TITLE | ゲーム名・メニュー（開始 / ヘルプ / 終了） | 開始→MODE_SELECT, ヘルプ→HELP(from TITLE), 終了→exit |
| MODE_SELECT | 「対コンピューター」（易・普・強）「2人で対局」「AI 対 AI（観戦）」 | 選択→MATCH_SETUP |
| MATCH_SETUP | vs AI: ランダム決定された石色を通知（例: 「あなたは白です。先手は黒」）。同卓: 黒番のプレイヤーを選択。AI 対 AI: 黒・白それぞれの強さ（易/普/強、既定 普/普）を選択 | 開始→PLAYING |
| PLAYING | 盤面+HUD（下記）| 合法手クリック→着手, ヘルプキー/ボタン→HELP(from PLAYING) |
| HELP | 潮汐ルールの説明 + Before/After 具体例（盤面図 2 枚） | 閉じる→復帰（対局なら同一状態） |
| RESULT | 勝敗（黒の勝ち/白の勝ち/引き分け）・最終スコア・盤面最終状態 | もう一度→MODE_SELECT, タイトル→TITLE |

## PLAYING HUD (常時表示 — FR-004/FR-008)

1. **盤面**: 8x8。石は黒/白の円。最外周リングは内側と判別可能な淡い枠/色味で強調（潮汐対象の可視化）。
2. **合法手マーカー**: 現在のプレイヤーの合法手マスを金色の脈打つ枠＋中央の点で示す（石と誤認しない形状）。マウスを乗せたマスには半透明の石プレビューと、その手で裏返る石を橙の輪で表示。HUD に「金色の枠のマスに置けます」と案内（2026-10-13 ユーザー指摘「置ける所が分かりにくい」により改訂）。
3. **手番表示**: 「黒 の番です / 白 の番です」。パス発生時は「◯ は置ける場所がありません — パス」と 1.5 秒表示。
4. **スコア**: 黒 n / 白 m（実時間更新）。
5. **潮汐カウント**: 「次の潮汐まで: N 手」+ 方向アイコン（時計 ↻ / 反時計 ↺）。N は TideClock.next_in と常に一致（SC-004）。
6. **AI レベル/モード表示**: 対AI時のみ「CPU: 普」等。

## Input contract

- クリック→マス変換: 盤面オフセット/マスサイズで決定。盤外・非法手・アニメ中・AI 思考中のクリックは無視（無音・無変化、FR-009）。
- H キーまたは画面ボタンで HELP。ESC は HELP 閉じる / PLAYING からはタイトル確認なしで MODE_SELECT。

## Animation contract (FR-010)

- 着手: 着石は即時表示、反転石は横幅収縮→膨張（約 300ms、全石同時）。完了まで入力ロック。
- 潮汐（FR-014、全体約 1000ms）: 「潮 汐」カットイン帯が画面を横切る（0–1000ms）。リングのスライド（約 500ms、
  250–750ms）と同時に、光の帯が回転方向へ外周を一周し、移動中の石から飛沫粒子が散り、盤が最大 6px 揺れて減衰する。
  完了後に盤状態を確定表示。
- 画面遷移（FR-015）: 遷移先画面を約 300ms で暗転からフェードイン。
- 結果（FR-015）: 結果パネルが右からスライドイン（約 450ms）、最終スコアを約 1 秒でカウントアップ、勝者がいれば紙吹雪粒子
  （対 AI で人間が負けた場合は出さない）。
- カウント 0→8 の切替は潮汐アニメ完了時。

## Sound contract (FR-010, 合成 PCM)

| Event | 音 |
|-------|-----|
| 着手 | 短いクリック |
| 反転あり | 上昇系ノイズ（反転と同時） |
| 潮汐発生 | 低い掃引音 |
| パス | 低い警告音 |
| 勝敗 | 勝ち: 明るい和音 / 引き分け: 単音 |

音量設定画面は作らない（YAGNI。静音でも成立する演出）。

## Help content contract (FR-011)

1. 基本オセロルールの 3 行要約
2. 潮汐の規則: 8 実手ごと・交互方向・石も移動・パスは計数しない
3. Before/After 具体例: 同一盤面の直前/潮汐後の 2 図 + 「角が消える」例示
4. 戦略ヒント 2 行（潮汐前に辺を制す 等）
